LANGKAH 1: PERMINTAAN IZIN KE TELEGRAM ADMIN (WAJIB)

----------------------------------------------------------------------
LANGKAH 2: PENGATURAN LOT & POSISI DI FILE CONFIG.JSON
----------------------------------------------------------------------
1. Buka file `config.json` menggunakan Notepad.
2. Secara default ukuran lot sudah diset `"default_lot": 0.05` (sama persis dengan akun Master).
   - Akun Cent (USC): Maksimal 3 posisi serentak
   - Akun Standard (USD): Maksimal 1 posisi (disiplin ketat)
   - Jika modal kamu kecil ($50 - $100) dan ingin lot lebih kecil, silakan ubah ke 0.01 Lot.
3. Simpan (Save) file `config.json`.

----------------------------------------------------------------------
LANGKAH 3: MENJALANKAN AUTO-COPIER
----------------------------------------------------------------------
1. Pastikan aplikasi MetaTrader 5 (MT5) di laptop/PC kamu SUDAH TERBUKA
   dan terhubung ke akun trading broker kamu (Exness, HFM, Octa, XM, dll).
2. Klik ganda file: `START_COPIER.bat`
3. Saat pertama kali dijalankan, kamu akan diminta memasukkan nomor HP Telegram:
   - Ketik nomor HP Telegram kamu (Bisa ketik 0812... atau +62812...).
   - ⚠️ PERHATIAN BESAR (KENAPA OTP SERING DIKIRA GAK MASUK):
     KODE OTP TIDAK DIKIRIM KE SMS PULSA HP!
     Buka APLIKASI TELEGRAM di HP atau PC kamu sekarang juga.
     Cari pesan dari chat resmi: "Telegram" (Centang Biru Resmi).
     Salin 5 angka kode OTP yang ada di chat Telegram tersebut (Contoh: "Login code: 12345").
   - Ketik kode OTP tersebut di layar copier lalu tekan Enter.
4. Setelah muncul tulisan:
   "✅ [LISENSI TERVERIFIKASI RESMI DARI MASTER ADMIN]"
   Artinya copier sudah berjalan! Biarkan jendela ini tetap terbuka.

----------------------------------------------------------------------

3. Timpa semua file ke folder copier kamu.
4. Klik ganda kembali `START_COPIER.bat` (Login Telegram tetap tersimpan).
